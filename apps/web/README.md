# Web dashboard

Next.js App Router dashboard for desk-based staff. Same Supabase project and RLS as mobile.

Not scaffolded. When Phase 7 in `docs/BUILD.md` starts:

```bash
cd apps
pnpm create next-app web --ts --app --eslint --tailwind --src-dir=false
```

Publishable key only in `NEXT_PUBLIC_*`. Pipeline, closing dates, compliance flags, spend. User/role admin for `super_admin`.
